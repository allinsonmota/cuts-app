# Optimizador de cortes de melamina

Build estático de la app, publicado en GitHub Pages.

**App online:** https://allinsonmota.github.io/cuts-app/

## Qué es

Una POC web que recibe una lista de cortes (piezas rectangulares) y los
distribuye sobre una o más placas de melamina maximizando el aprovechamiento
del material — algoritmo de empaquetado (MaxRects / guillotina), soporte de
canto, importación por CSV, plano visual y reporte en PDF.

El acceso está restringido: hace falta iniciar sesión con Google y ser
aprobado manualmente por el administrador.
